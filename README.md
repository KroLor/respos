# Резервная одометрия трамвая — ветка `algorithm`

Ветка разработки модели движения трамвая — ROS 2 пакета `tram_backup_odometry`.

**Итоговое решение для жюри — в ветке [`main`](https://github.com/KroLor/tram-backup-odometry/tree/main)**:
нода `tram_odometry` из ветки [`interface`](https://github.com/KroLor/tram-backup-odometry/tree/interface)
использует эту модель как основной оценщик.

## Что в ветке

```
src/tram_backup_odometry/  модель: ядро без ROS — фильтр Калмана по скоростям тележек с откалиброванной
                           моделью тягового привода и продольной динамики (задержка, инерционность,
                           уклон, кривые, ограничение по сцеплению), эхо-сеть как обучаемая поправка,
                           отбраковка проскальзывания и юза, выставка по GNSS, карта пути со стрелками,
                           путями выезда и местами остановок; положение base_link в системе судьи (MGRS);
                           своя нода и launch, конфиг, данные карты, 11 тестов (в том числе golden-тест
                           по bag стенда организаторов)
docs/MODEL.md              математическая модель, входные и выходные переменные, допущения,
                           ограничения, план развития
docs/INTEGRATION.md        контракт ядра и встраивание в другой ROS-рантайм
docs/images/               схема модели (PNG) и её исходник draw.io
bench/                     офлайн-стенд: прогоны датасета × 13 сценариев сбоев, метрики, отчёты
                           (данные готовит tools/extract_bags.py из bag датасета)
tools/                     извлечение данных из bag, построение карты пути, калибровка модели,
                           golden-данные
reports/                   калибровка и проверка точности
```

## Проверка

```bash
cd src/tram_backup_odometry
python3 -m pytest -q test      # 11 тестов, нужен numpy; ~4 с
```

Сборка и запуск ноды модели — [`src/tram_backup_odometry/README.md`](src/tram_backup_odometry/README.md).
Пакет сообщений `tram_vehicle_msgs` берётся у организаторов. При осознанном изменении ядра
golden-данные пересоздаются по [`docs/INTEGRATION.md`](docs/INTEGRATION.md), §5.
